# MetaRubric project page

Static GitHub Pages site for **MetaRubric: Learning to Reward for Rubric-Based Reinforcement Learning**.

The page uses the manuscript's current abstract, a paper PDF at `assets/metarubric.pdf`, and an image rendered from `figures/metarubrics_overview.pdf`. GitHub Pages can serve the repository root directly; `.nojekyll` disables Jekyll processing.

To preview locally, run `python3 -m http.server` in this directory and open the displayed local address.
